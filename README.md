# Blog Web Application

This is a blog web application that provides authentication, blog management, and an admin dashboard for extended control.

## Features

### Authentication
- Login with **email and password** or using **Google authentication**.
- Secure authentication system with session handling.

### User Features
- View all **approved blogs** after logging in.
- Browse **own blogs**.
- **Create new blogs**.
- **Manage and view** own profile.
- **Upload a profile image**.
- **Upload an image** to blog posts.
- **Delete** only their own blogs.
- **Filter blogs by tags** by clicking on the tag.

### Admin Features
- Access to an **admin dashboard**.
- **Approve** or **delete** blogs.
- **View and manage** all users and blogs.
- **Delete users**.
- View **detailed user profiles**, including a table of all their blogs.
- **Edit user credentials**.
- **Filter blogs** by approval status (approved / not approved).
- **Search** blogs and users by name.

## Technologies
- **Next.js** (React Framework)
- **TailwindCSS** (Styling)
- **Cloudflare** (Image handling and optimization)
- Authentication with **Credentials** (email/password) and **Google OAuth**
